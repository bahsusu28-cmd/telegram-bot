# 🤖 Telegram Bot с проверкой подписки

Многофункциональный Telegram бот с проверкой подписки на канал, мультиязычностью и профилями пользователей.

## ✨ Функции

- ✅ Проверка подписки на канал
- 🌍 45 языков интерфейса
- 👤 Профили пользователей
- 📊 Статистика использования
- 📱 Сохранение номера телефона
- 💾 База данных SQLite

## 🚀 Локальный запуск

```bash
# Установите зависимости
pip install -r requirements.txt

# Запустите бота
python bot.py
```

## 🌐 Деплой на сервер

Смотрите инструкцию в [DEPLOY.md](DEPLOY.md)

## ⚙️ Настройка

1. Получите токен бота у @BotFather
2. Добавьте бота в канал как администратора
3. Укажите токен и канал в `bot.py` или переменных окружения

## 📝 Переменные окружения

- `BOT_TOKEN` - токен вашего бота
- `CHANNEL_USERNAME` - username канала (например, @verised)

## 🛠 Технологии

- Python 3.11
- requests
- SQLite3
